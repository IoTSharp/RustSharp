# P4 granular work: HTTP and WebSocket profiles

English | [简体中文](P4_zh.md) | [Main roadmap](../../ROADMAP.md)

All rows are ⏳ Planned. These leaves retain the five P4 parent commitments and the hard P3 prerequisite. They describe exact-version Rust# API profiles, not unchanged upstream crate source compatibility. New `compat/`, sample, profile, test and runtime subdirectories below are planned deliverables, not claims of existing implementation. Existing `src/RustSharp.Runtime/`, `tools/RustSharp.Conformance/`, `eng/` and `.github/workflows/` provide integration roots. Listed `rsc test`/`rsc publish` commands become executable only once the named workspaces, profiles and CLI support have been delivered.

Each contract leaf must freeze a nonempty versioned manifest: exact upstream/dependency versions, API signatures, feature combinations, wire-protocol rules, exclusions, fixture IDs, expected results, numeric limits and fixed denominator/hash. Protocol versions/extensions and crate versions must be explicitly decided there. Implementation leaves consume that inventory; scope expansion creates a new version and never removes or weakens existing cases. Local controlled endpoints replace public-service assumptions in required tests.

Each leaf owns named code and corresponding positive, negative, boundary and budget tests. Assign individual files before parallel work in shared roots. Evidence cells name future deliverables; no existing result is implied. A planned report `artifacts/roadmap/<ID>.json` records final source SHA, locked package hash, profile/manifest/version/hash, exact denominator/results, tools, platform/RID/runtime, commands, finite timeout/retry/item limits, PID/start/parent, failure reasons and owned-resource cleanup. Reports must be archived by CI with stable run links; all included cases run with zero failures/skips. A successful smoke sample alone cannot close an API/feature denominator.

A parent ID means every listed child has accepted evidence. A leaf can close after its own dependencies and evidence pass; it does not depend on its own phase gate. `P4-GATE` means the four gate rows at the end. P3-GATE remains mandatory before P4 closes, and P4-01 retains its original full P3 dependency. No gate claims the whole upstream crate ecosystem.
