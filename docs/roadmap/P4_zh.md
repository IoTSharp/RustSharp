# P4 颗粒化任务：HTTP 与 WebSocket 配置档

[English](P4.md) | 简体中文 | [主路线图](../../ROADMAP_zh.md)

所有行均为 ⏳ 计划中。这些叶子保留五项 P4 父任务承诺与 P3 硬前置条件。它们描述精确版本 Rust# API 配置档，不承诺上游 crate 源码原样兼容。下列新增 `compat/`、示例、配置档、测试与运行时子目录为计划交付物，不表示实现已存在。现有 `src/RustSharp.Runtime/`、`tools/RustSharp.Conformance/`、`eng/` 与 `.github/workflows/` 提供集成根目录。所列 `rsc test`/`rsc publish` 命令仅在具名工作区、配置档与 CLI 支持交付后可执行。

每个合同叶子必须冻结非空版本化清单：上游/依赖精确版本、API 签名、feature 组合、线协议规则、排除项、夹具 ID、预期结果、数值上限与固定分母/哈希。协议版本/扩展与 crate 版本必须在该叶子明确决定。实现叶子消费此清单；扩大范围需新增版本，不得删除或放宽已有用例。必需测试使用本地可控端点，不假设公网服务可用。

每个叶子负责具名代码及对应正向、负向、边界与预算测试。共享根目录并行工作前分配具体文件。证据列列出未来交付物，不暗示现有结果。计划报告 `artifacts/roadmap/<ID>.json` 记录最终源码 SHA、锁定包哈希、配置档/清单/版本/哈希、准确分母/结果、工具、平台/RID/运行时、命令、有限超时/重试/项目上限、PID/启动时间/父进程、失败原因与自有资源清理。CI 必须归档报告并提供稳定运行链接；全部纳入用例运行且零失败/跳过。单个冒烟示例成功不能关闭 API/feature 分母。

父 ID 表示其全部子项已有认可证据。叶子在自身依赖与证据通过后即可关闭，不依赖所属阶段门禁。`P4-GATE` 表示末尾四项门禁。关闭 P4 前仍必须满足 P3-GATE，且 P4-01 保留原有完整 P3 依赖。任何门禁都不声明兼容整个上游 crate 生态。
