## Scope and evidence baseline

This inventory assigns existing commitments to stable IDs without expanding or shrinking the language contract. P1-06.01 must enumerate the [typed MIR contract](../typed-mir-profile.md), [P1 gap matrix](../p1-gap-matrix.md) and original acceptance requirements. The existing check-only type profile stays check-only; previously promised executable behavior and listed remaining work cannot disappear through reclassification. References/provenance, slices/unsizing, patterns/closures, full source move/borrow analysis, generated Drop/panic, source package contracts and every required backend each need leaves and cases.

There is no complete exit candidate yet. New v3/v2 suite names and new files below are **planned deliverables**, with no new denominator or passing result claimed. Complete the per-case inventory and integer denominators in P1-10.01/.02 first. Existing 8/8, 5/5, 24/24, 16/16, 12/12 or 6/6 results cannot automatically close the expanded contract.
